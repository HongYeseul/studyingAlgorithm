# 104. Maximum Depth of Binary Tree

- 플랫폼: LeetCode
- 난이도: Easy
- 문제: https://leetcode.com/problems/maximum-depth-of-binary-tree

## 문제 설명

Given the `root` of a binary tree, return <em>its maximum depth</em>.

A binary tree's <strong>maximum depth</strong> is the number of nodes along the longest path from the root node down to the farthest leaf node.

<strong>Example 1:</strong>

![](https://assets.leetcode.com/uploads/2020/11/26/tmp-tree.jpg)

```
Input: root = [3,9,20,null,null,15,7]
Output: 3
```

<strong>Example 2:</strong>

```
Input: root = [1,null,2]
Output: 2
```

<strong>Constraints:</strong>

- The number of nodes in the tree is in the range `[0, 104]`.
- `-100 <= Node.val <= 100`
