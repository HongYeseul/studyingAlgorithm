# 53. Maximum Subarray

- 플랫폼: LeetCode
- 난이도: Medium
- 문제: https://leetcode.com/problems/maximum-subarray

## 문제 설명

Given an integer array `nums`, find the with the largest sum, and return <em>its sum</em>.

<strong>Example 1:</strong>

```
Input:nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]Output: 6
Explanation: The subarray [4,-1,2,1] has the largest sum 6.
```

<strong>Example 2:</strong>

```
Input:nums = [1]Output: 1
Explanation: The subarray [1] has the largest sum 1.
```

<strong>Example 3:</strong>

```
Input:nums = [5, 4, -1, 7, 8]Output: 23
Explanation: The subarray [5,4,-1,7,8] has the largest sum 23.
```

<strong>Constraints:</strong>

- `1 <= nums.length <= 105`
- `-104 <= nums[i] <= 104`

<strong>Follow up:</strong> If you have figured out the `O(n)` solution, try coding another solution using the <strong>divide and conquer</strong> approach, which is more subtle.
