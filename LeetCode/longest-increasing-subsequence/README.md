# 300. Longest Increasing Subsequence

- 플랫폼: LeetCode
- 난이도: Medium
- 문제: https://leetcode.com/problems/longest-increasing-subsequence

## 문제 설명

Given an integer array `nums`, return <em>the length of the longest <strong>strictly increasing</strong></em> .

<strong>Example 1:</strong>

```
Input:nums = [10, 9, 2, 5, 3, 7, 101, 18]Output: 4
Explanation: The longest increasing subsequence is [2,3,7,101], therefore the length is 4.
```

<strong>Example 2:</strong>

```
Input:nums = [0, 1, 0, 3, 2, 3]Output: 4
```

<strong>Example 3:</strong>

```
Input:nums = [7, 7, 7, 7, 7, 7, 7]Output: 1
```

<strong>Constraints:</strong>

- `1 <= nums.length <= 2500`
- `-104 <= nums[i] <= 104`

<strong>Follow up:</strong> Can you come up with an algorithm that runs in `O(n log(n))` time complexity?
